Measure what we can.
Label the limits.

A privacy-preserving click counter is active in this browser only. It does not report to a server, count visitors across devices, or measure Amazon orders.

Deployment limitation: GitHub Pages serves static files and cannot host a custom server-side analytics endpoint. No self-hosted endpoint, Search Console property, or authorized Associates report is connected. Cross-visitor analytics and conversion measurement are therefore not live.

This browser’s outbound click count

Counts below are stored in this browser's local storage. They are aggregate click counts by submitted link label; this counter sends no IP address, cookie ID, full referral URL, or browsing profile to an analytics endpoint. GitHub separately states that Pages visitor IP addresses are logged for security purposes in its Pages data-collection documentation. Clearing this browser's site data clears these local counts.

What it takes to measure beyond this browser

A production analytics endpoint needs a separately hosted service, a privacy and retention policy, and verification that its collection and deployment comply with applicable law and platform terms. Authorized order data must come from official Associates reporting, not a browser click counter. No endpoint URL or account credentials were supplied, so no endpoint is configured here. No reader sign-up form or mailing-list provider is configured, and this publication does not collect email addresses.
