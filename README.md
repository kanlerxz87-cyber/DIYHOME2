# DIYHOME2 — DIY Home Upgrades

Amazon Associates publication for DIY home upgrades. Fully static site generated by a stdlib-only Python build (`tools/build.py`), deployed to GitHub Pages by GitHub Actions.

- **Site:** https://kanlerxz87-cyber.github.io/DIYHOME2/ (after the Pages workflow finishes on `main`)
- **Local preview:** `python3 -m http.server -d docs 8080` → http://localhost:8080/
- **Rebuild:** `python3 tools/build.py && python3 tools/check_links.py`
- **Coordination / task board:** `COORDINATION.md`
- **Executive summary:** `EXECUTIVE_SUMMARY.md`
- **Evidence:** `data/source-register.json`, `data/product-intent-confirmation.json`, `data/campaign-ledger.csv` (empty headers by design), site page **Verification register** and **Flagged for Review** (F-001..F-010)

Tracking ID: `shopnow047c-20`. All outbound product links are `rel="sponsored nofollow noopener"`. As an Amazon Associate we earn from qualifying purchases.

**Read `EXECUTIVE_SUMMARY.md` before relying on any product data on the site — Amazon was unreachable from the build environment; product attributes are intentionally blank and flagged.**
