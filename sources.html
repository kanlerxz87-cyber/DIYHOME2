What these documents constrain

Six rules follow directly from the sources above. They are the reason this site shows no prices, no star ratings and no price alerts, and the reason links are plain rather than shortened.

IDConstraintBasisEffect on this site
C1No prices may be displayed without API access or an Amazon-served link.S02No price appears anywhere. Price comparison cannot be offered.
C2No star ratings, review counts or review text may be displayed without API access.S02No rating appears anywhere. A rating column would be a policy breach, not a design choice.
C3No price tracking or price alerting.S02A price-history or deal-alert feature was excluded deliberately, not overlooked.
C4Filtering or styling a link so it is unclear it goes to Amazon is prohibited.S02Links are plain, unabbreviated Amazon URLs. No cloaking, no intermediary.
C5A purchase arriving through an intermediate site without an affirmative action there is disqualified.S02Click tracking may not route the visitor through this domain. A beacon is the compliant pattern.
C6A short code is not an ASIN and must not be recorded as one.S06, S10, S11, S12Intended and observed fields stay separate; the intended fields remain blank.
C7Each link placed on the site to an Amazon Site must carry the Associates ID (tag, format XXXXX-##) as a URL parameter.S02The untagged Amazon reference links on three guide pages are in tension with this rule. They are published as reference-only, marked sponsored, and flagged as F12 for a decision.
C8An autonomous or semi-autonomous Agent that accesses Program Content must identify itself in its user agent as Agent/[name], must not conceal that it is an Agent, and must stop if Amazon asks it to.S02No Program Content (API data, link formats, widgets) is used, so the Agent Terms are not engaged today. Flagged as F11 because the project brief describes an automated agent.

Amazon listing and redirector URLs are printed as plain text so they can be copied and checked by hand. A citation is evidence, not a product offer, so citations are never made into Amazon links. The three buying guides do carry one untagged, reference-only Amazon link each, marked sponsored; that sits in tension with the tag-in-every-link rule (C7) and is published as flag F12 rather than hidden.
