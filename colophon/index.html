How the pages are made.

Static HTML, generated from JSON, published from a public repository. No CMS, no database, no framework, no third-party scripts.

Stack

  • Pages generated by scripts/build.mjs — a single Node script with no dependencies.
  • Data lives in data/*.json: products, links, sources, flags, guides, ledger schema.
  • Type: the reader's system serif for headings, system sans for text. No web fonts are downloaded.
  • No analytics library, no tag manager, no CDN. One CSS file, one small script.

Checks before publish

  • scripts/audit.mjs walks every generated page and fails the build on a broken internal link, a missing disclosure strip, an outbound link without rel="sponsored", or a table row with no source.
  • The feed and sitemap are generated from the same data as the pages, so a page cannot exist in one and not the other.

Accessibility

  • Semantic landmarks, one h1 per page, labelled tables with captions and row headers.
  • Skip link, visible focus rings, and a reduced-motion preference that removes all transitions.
  • Colour pairings chosen to keep body text above 4.5:1 contrast in both light and dark schemes.

Reproducing this site

Clone the repository, run node scripts/build.mjs, then node scripts/audit.mjs. The build is deterministic: the same data produces byte-identical pages.
