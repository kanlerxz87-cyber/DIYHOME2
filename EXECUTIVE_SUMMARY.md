# Executive Summary — DIY Home Upgrades (Amazon Associates publication)

**Date:** 2026-11-20 · **Repo:** kanlerxz87-cyber/DIYHOME2 · **Branch:** arena/7ebfbe32-diyhome2 · **Selected tracking ID:** `shopnow047c-20` · **Live site (after merge + Pages enable):** https://kanlerxz87-cyber.github.io/DIYHOME2/

## 1. What this is
A GitHub Pages publication ("DIY Home Upgrades") targeting DIY home-upgrade buyers, built around the three submitted affiliate links. Static site generated by a stdlib-only Python build (`tools/build.py`) from JSON data files; deployed by GitHub Actions to GitHub Pages. No frameworks, no tracking scripts, no backend required.

Submitted links (intended ASINs in parentheses): `https://link.amazon/B0hmGG4m2` (B0hmGG4m2), `https://link.amazon/B03QDuGdo` (B03QDuGdo, submitted **twice**), `https://link.amazon/B0hpD2JGQ` (B0hpD2JGQ).

## 2. The one finding that shapes everything
**Amazon hosts (`amazon.com`, `link.amazon`, `affiliate-program.amazon.com`) are unreachable from this build environment** (TLS connection failures). Therefore:

- No product title, price, rating, availability, image or spec could be verified against an official source. All such values are **blank** and flagged (F-001/F-004/F-005); nothing was inferred or filled in.
- The supplied short links are **not declared valid or invalid** — their compliance status is **unresolved** (F-003). Amazon's Operating Agreement requires Special Links to use the Program's tagged formats; confirmation requires an enrolled Associates workflow test (destination + tracking report), which the owner must execute.
- The candidate listing URLs (`https://www.amazon.com/dp/<ASIN>`) are stored as a **separate** `candidate_listing_url` field, marked constructed/unverified, and are never merged with confirmation fields (`official_listing_url`, `confirmation_date`, `confirmation_source`). Observed redirect targets are a separate empty field.
- FTC and Amazon policy pages were verified only via web-search excerpts (2026-11-20); access method is recorded per source on the site's Verification page.

## 3. What shipped
- Publication front page (masthead, amber disclosure strip above the fold — repeated in footer — on **every** page), 4 question-shaped guides (working titles, explicitly not popularity claims), RSS feed (`feed.xml`) auto-generated from `data/guides.json`, `sitemap.xml`, `robots.txt`, JSON-LD (WebSite/Article/FAQPage), Open Graph.
- Products register (2 tables: display + product-intent confirmation record) and an enrollment-test checklist.
- "Explore" nav group holding every dashboard surface; footer repeats them all.
- Measurement: five defined events (`page_view`, `guide_read`, `affiliate_outbound_click`, `feed_subscribe_click`, `reader_capture_submit`), localStorage-only by default, optional self-hosted stdlib collector (`tools/collector.py`) + `DIYHOME_ENDPOINT` config; reader-capture form **inert** until configured (SG-30).
- Campaign ledger: headers only (`recorded_at, source, channel, eligible_sessions, clicks, reported_orders, order_value, provenance`); no conversion score or forecast anywhere.
- Flagged for Review page: 10 items (F-001..F-010) with source links and required owner actions.
- Editorial standards + weekly Tuesday cadence (next 2026-11-24); new guides automatically enter sitemap and feed on rebuild.

## 4. Compliance posture
- Verbatim Operating Agreement sentence "As an Amazon Associate I earn from qualifying purchases." — above the fold and in footer, every page (F-009 flags wording/placement for owner review).
- Every outbound product link: `rel="sponsored nofollow noopener"`, target `_blank`, ↗ marker, sponsored-links box per article.
- No Amazon imagery, listing copy or trademarks beyond nominative use with attribution; no prices shown; no scraped data; no API access attempted.
- FTC 16 CFR Part 255: material-connection disclosure unavoidable on every page (electronic media).
